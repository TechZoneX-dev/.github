# Security policy

Please **do not report security vulnerabilities in public issues, discussions or
pull requests.**

Report them privately with GitHub's **Report a vulnerability** button on the
affected repository's **Security** tab. If you can't see that button, you don't have
access to report there; open a minimal public issue that asks for a private contact,
without any vulnerability details.

We acknowledge reports as soon as we can and keep you updated until the issue is resolved.
